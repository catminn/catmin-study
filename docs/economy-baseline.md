## 等级

升到第 L+1 级需要累计经验 60·L·(L+1)/2（L=1 → 60，L=2 → 180，L=3 → 360……）。经验只增不减（消费不扣经验）。

## 对新引擎的含义（提议，待 ChatGPT/Catherine 看）

1. 旧经济的所有“按行为给分”都是**自报或点击**，没有学术证据门槛。新引擎的奖励必须来自 `verification=confirmed` 的事件，二者不能混算。
2. 旧积分是单一数字（points）+ 经验（xp）。v2 要求的 RealPoints / BaseMaterials / WorldItems / Discoveries / Mastery 分账，我提议：**RealPoints 继续就是旧的 points**（同一个账本），其余四类为新增，不进旧 state 文档。这样旧页面完全不受影响，也不用拆分旧余额。需要 Catherine 确认。
3. 每日可得上限的粗略量级：签到 ~30–50 + 专注最多 4 轮（8–30 each，最多约 120）+ 小测最多 3×40 + 战斗命中 30 + 击倒/掉落若干 ≈ 300–450/天。新引擎单次奖励应明显低于现有的单次专注/小测奖励，避免通货膨胀。
