# 主神空间：职责与协作约定

- **ChatGPT（主负责人）**：整体产品新架构、游戏规则与玩法、学习型 DM、世界及剧情的创作、隐秘叙事设计、跨模块整合和工程实施推进。负责最终结构决策及技术规范。
- **Claude（设计负责人）**：视觉表达、界面布局、交互体验、UI/UX 设计及实现建议。可在 ChatGPT 需要时协助技术评审、问题排查与代码建议；这不改变架构/玩法/剧情的主要负责关系。
- **用户**：确定体验偏好与产品目标，对关键变更进行验收。
- **保密约束**：所有面向玩家的讨论和设计审核不披露正式剧情、隐藏世界真相、NPC 秘密和未来事件。剧情创作及隐藏数据与玩家可见文档严格隔离。
- **发布约束**：不在未经隔离测试、备份与恢复验证之前更改正式存档或合并部署新引擎。当前页面仍以 `page/zhushen.html` 为唯一源码。UI 相关更改交由 Claude 主导设计。
- **架构原则**：学习在冒险中发生；学习正确性与游戏随机判定独立；知识进度/奖励账本/游戏事件可追溯，隐藏信息与玩家认知相隔离。
