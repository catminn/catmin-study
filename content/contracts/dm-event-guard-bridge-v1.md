# DM beat ↔ committed event guard route identity — author bridge v1

This **synthetic, spoiler-free author-only** cross-check links the two DM route beats and their conditional convergence callbacks to the corresponding guarded committed transitions. It prevents an independently valid beat sheet and independently valid guard plan from accidentally assigning a route's callback or public copy slot to the other route.

Call "validateDmBeatFlow(flow)" and "validateDmEventGuards(guards)" **separately** first; both must pass. Then call "validateDmEventGuardBridge(flow, guards, bridge)". The bridge deliberately checks cross-contract identity only and does not replace either source validator. It accepts exactly {schemaVersion:'dm-event-guard-bridge-v1',synthetic:true,worldId,manifestRevision,routes:[...]} with exactly two route bindings. Each binding names routeBeatId, traceRef, choiceTransitionId, choiceEventRef, choiceCopySlot, callbackTransitionId, callbackEventRef, callbackCopySlot. All identifiers must be author-safe synthetic IDs. No actual dialogue, hidden facts, NPC identity, puzzle answers, or real-world identifiers belong in the bridge.

The bridge matches route beats to guarded choice transitions, then matches the route's convergence callback to the guard's route-specific committed callback transition and its approved public-copy slot. It requires distinct IDs, no unreviewed bridge fields, and disallows reuse of a guard choice slot as a DM presentation slot. The only intentional cross-contract copy-slot reuse is the *same route's* convergence callback. Diagnostics are fixed error codes without input values.

Native Node.js 22 regression command: "node --test test/dm-event-guard-bridge.test.mjs". The synthetic tests verify mapping, ordering, mismatches, collisions and non-echoing diagnostics. **Limitations:** This is a static author consistency check. It cannot establish that the real Worker commits the expected event, that a renderer gates the callback, that a private copy was reviewed, or that a route has meaningful narrative consequences. It is not wired to CI, production, import, or real saves.
