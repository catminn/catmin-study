# World 01 route agency cross-check v1 — synthetic authoring only

This is a **spoiler-free, offline** consistency check for the public first-world mechanical skeleton (`world01-opening-skeleton.json`) and its synthetic causal outline (`world01-causal-authoring-v1.json`). It is not a runtime validator, private-world review, story storage mechanism, production authorization, or import gate.

`validateWorld01RouteAgency(world, causal)` requires two distinct committed exits from one choice scene, exactly matching that scene's outgoing options. Each branch must reach a shared convergence without visiting the other branch beforehand, and every pre-convergence continuation must have a path to that reunion. A reachable cycle **before** convergence is rejected with `route_cycle`, even when an optional exit exists: reachability alone cannot guarantee that a player will ever leave a loop. This strict first-world authoring check does not forbid post-convergence revisits or establish a general rule against free exploration loops in other worlds. The two committed events need unique identities and route traces. Each event must produce its own NPC relationship state, and the post-convergence outcome mapping must preserve those differences and the committed event history.


The opening is identified by a unique `orientation` node (as in the first-world skeleton), or by a unique zero-incoming-edge root when no orientation is declared. Every node must be reachable from that opening. The committed choice must dominate the branch entries, shared reunion, and endings: an opening-to-branch/reunion/terminal bypass or a pre-choice cycle fails closed with `choice_bypass`. Ambiguous openings fail with `entry_invalid`; disconnected nodes with `graph_unreachable`. A valid acyclic approach to the choice and post-reunion revisits, including a return to the opening, remain legal when the opening is explicitly marked. These are strict first-world mechanical authoring checks, not a restriction on other worlds' exploration structures.

Optional learning must be offered in **both** route scenes, with explicit player consent and a nonacademic continuation. This does not mean the player must complete a practice or that the academic work has been verified. The author-side check also rejects fabricated measurements and narrator-committed effects. All errors are fixed codes without IDs or text; input is not mutated.

Run `node --test test/world01-route-agency.test.mjs` under Node 22. The 32 synthetic tests cover successful and reversed-route registration, collapsed choices, mismatched exits, invalid commits, cross-route bleed, missing convergence, self-loops and multi-scene pre-convergence cycles, legal acyclic detours and post-convergence revisits, opening-choice bypasses and pre-choice cycles, disconnected scenes, NPC state erasure, incorrect consequence attribution, lost route memory, one-sided learning and forced academic gates. This is a **separate cross-check**, not a replacement for the existing world01 causal lint, DM/NPC bridge, scene-learning validation, real Worker/D1 tests or model experience review.

The first formal world remains **DO-NOT-IMPORT**. No private plot, character identity, hidden fact, answer, approved dialogue, or production state belongs in this contract or its tests. Real per-field private review and Catherine's explicit authorization are required before any official-world import.
